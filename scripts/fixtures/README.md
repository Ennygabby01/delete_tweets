# Screenshot fixtures

`demo-avatar.jpg` is a 128px crop of an
[Unsplash sample portrait](https://images.unsplash.com/photo-1472099645785-5658abf4ff4e),
used under the [Unsplash License](https://unsplash.com/license).
The fictional demo account does not identify or represent the person photographed.
The photo is a separate third-party asset; the repository's MIT license does not
replace its license.

The capture script serves this file through its intercepted demo origin. Browsers
never request Unsplash or X while generating screenshots. No real account profile
or personal archive is used.
